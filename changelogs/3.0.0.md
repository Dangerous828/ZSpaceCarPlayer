# ZSpaceCarPlayer v3.0.0 Changelog

**版本：** v3.0.0  
**更新日期：** 2026-09-08  
**适配系统：** Android 4.3 / API 18 (吉利 8600 经典固件)  

> v3 是**音频链路重构**（非 UI/架构重构）：自研 C++ 原生 DSP 引擎 + 原生无损软解 + 流式抗抖动缓冲 + 双引擎可回退，并补齐崩溃监视与引擎熔断保护。系统引擎路径的全部既有加固保持不变。

## 📦 回滚基线

* 上一发布版本为 **v2.3.0 (versionCode 2)**，回滚包：`apks/release/ZSpaceCarPlayer-2.3.0-code2-debug.apk`（**debug** 构建——项目无签名配置，release 包不可安装，车机实际安装形态也是 debug）。构建自 `main` @ `8b1999d` 的**独立 git worktree**，未混入任何 v3 改动；SHA-256 `2c858d60…2bc256`，来源与重建命令见同目录 `README.md`。
* 回滚方式：`adb install -r` 覆盖为 2.3.0 需先卸载 3.0.0（versionCode 不可降级安装），本地 SQLite 缓存与 SharedPreferences 随卸载清除，重新首启会自动同步曲库，不影响服务端数据。
* 引擎层面另有独立回退通道：设置页「播放引擎」切回系统即绕过全部 v3 代码路径（Native DSP、软解、环形缓冲代理均不参与），崩溃熔断锁存时也会自动处于该状态。
