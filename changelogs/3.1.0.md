# ZSpaceCarPlayer v3.1.0 Changelog

**版本：** v3.1.0 (versionCode 4)  
**更新日期：** 2026-09-13  
**适配系统：** Android 4.3 / API 18 (吉利 8600 经典固件)  

> v3.1 主线是**远程升级（OTA）**：版本清单 + APK 托管在 `web.kentonnie.top/zspace/update/`，车机启动静默检查、设置页手动检查、下载校验 sha256 后拉起系统安装界面由车主确认。同步合入缓冲/预取、坏断点纠偏、音量意图、连接诊断等实车修复。

## 📦 分发与回滚

* 分发包：`ZSpaceCarPlayer-3.1.0-code4-debug.apk`（debug 签名，与车机已装包同签名可覆盖安装），sha256 `03c54830…1a5507`，3,101,460 字节。已托管 `https://web.kentonnie.top/zspace/update/`，清单 `latest.json` versionCode=4。
* 车机 vc≤3 启动即静默检查发现新版；覆盖安装不丢 SQLite 缓存与 SharedPreferences。
* 回滚：vc 不可降级安装，需先卸载再 `adb install` 旧包（数据随卸载清除，首启自动同步曲库）；或设置页「播放引擎」切系统引擎绕过全部 v3 路径。
