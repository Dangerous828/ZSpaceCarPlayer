# ZSpaceCarPlayer v3.1.1 Changelog

**版本：** v3.1.1 (versionCode 5)  
**更新日期：** 2026-09-17  
**适配系统：** Android 4.3 / API 18 (吉利 8600 经典固件)  

> v3.1.1 主线是**现场诊断闭环与远程升级固化**：新增播控栏与设置页双入口一键上报诊断现场、车机重启不丢的 DiagLog 滚动日志、logcat 白名单降噪；彻底解决 Android 4.3 与 Cloudflare ECDSA 证书的 TLS 握手缺陷；修复 OTA 升级包权限导致的系统解析失败，完成首个端到端远程升级闭环。

---

## 📝 变更记录

| 序号 | 模块 | 变更类型 | 内容描述 | 日期 |
|:---:|:---:|:---:|:---|:---:|
| 1 | Diag | `feature` | **双入口一键上报诊断日志**：播控栏最左侧新增「上报」快捷按钮（卡顿/缓冲异常现场即时抓取）、设置页新增「立即上报诊断日志」；带 `triggerSource` 标识（`playback_bar` / `settings_page`），后台线程异步上报并给予防重置灰与 Toast 反馈 | 2026-09-16 |
| 2 | Diag | `feature` | **DiagLog 滚动持久化日志**：新增 `filesDir/diag.log`（+ `diag.log.1`）双文件滚动落盘（各 96KB 安全截断），车机异常断电或进程重启现场不丢失；上报时自动按时间序拼合回传 | 2026-09-16 |
| 3 | Diag | `feature` | **Logcat 白名单精准降噪**：过滤车机 Canonical 系统日志中大量刷屏的导航进程（NaviServer 等）噪音；仅保留本应用各子系统 Tag 与系统音频关键链路（AudioTrack / AudioFlinger / MediaPlayer / MediaCodec / OkHttp）；crash 缓冲区信号行原样保留 | 2026-09-16 |
| 4 | Network | `fix` | **Android 4.3 TLS 密码套件与证书链修复 (`TlsCompat`)**：Cloudflare / Caddy 仅提供 256 位 ECDSA 证书，Android 4.3 Conscrypt 仅支持 CBC 类 ECDSA（`TLS_ECDHE_ECDSA_WITH_AES_128_CBC_SHA`）。OkHttp 3.12 默认 `MODERN_TLS` 会在握手前将该套件过滤剔除导致握手交集为 0（报 `sslv3 alert handshake failure`）。通过 `ConnectionSpec.allEnabledCipherSuites()` 解除二次过滤，并由 `TlsCompat` 统一挂载内置 GTS Root R4 根证书与 SNI 注入 | 2026-09-17 |
| 5 | OTA | `fix` | **系统安装器权限修复 (`makeReadableForInstaller`)**：低版本 Android（API < 24）跨应用调用系统安装器走 `file://` 协议；下载到应用私有目录的 APK 默认权限为 700/600 导致系统安装器 UID 报 `EACCES`、界面报「解析程序包时出现问题」。在校验重命名与拉起 Intent 阶段自动放开 `setReadable(true, false)` 与目录 `setExecutable(true, false)` | 2026-09-17 |
| 6 | UI | `feature` | **YouTube 式双层缓冲进度条**：在深色轨道与青绿播放头之间插入浅色半透明缓冲层（`seek_buffer_bg.xml`），播放器持续上报缓冲百分比，直观呈现领先量 | 2026-09-13 |
| 7 | UI | `feature` | **播放自动跟随歌单**：播放时左侧列表根据当前曲目来源智能切回对应歌单或自动按目录/流派反推歌单，配合列表平滑滚动与高亮居中 | 2026-09-14 |
| 8 | Service | `fix` | **静音键逻辑优化 (`SystemMuteMonitor`)**：监听系统静音状态跳变，将物理静音键与播放/暂停控制解耦，杜绝误触发 | 2026-09-15 |
