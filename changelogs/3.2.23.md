# 3.2.23 (versionCode 34)

发布日期：2026-10-23

## 变更

1. 新增手选“高品”档：无损 → 高品 → 流畅循环；默认仍为无损，正在播放的歌曲不切换音源。高品档播放 NAS 预转的 AAC-LC 512kbps 文件，目标规格 44.1kHz 立体声，约需 65KB/s。
2. 为 FLAC/WAV 原曲生成独立 512kbps M4A 副本，保留原件与标签。副本存放在 Jellyfin 独立“车载高品”音乐库，按相对路径映射回原曲；客户端导入时过滤副本条目，因此主歌单不会出现重复曲目。
3. SQLite v6 为曲目缓存增加高品副本 ID。设备升级时只增加可空字段，保留收藏、播放次数与进度；`SharedPreferences` 中的档位值 `1` 继续表示“流畅”。
4. 高品副本暂未建立映射时回退到流畅档，避免误拉无损大文件；已压缩的 MP3/M4A 使用自身原件 URL。
5. 把缺少流派元数据的歌曲卡片标为“无流派标签”，并让空 folder_name 使用不参与文件夹聚类的占位值。Jellyfin 当前主库 796 首中 794 首没有 Genres/GenreItems；它们仍可按实际父目录浏览。
